【运营商DNS劫持与非法广告注入举报】

一、基本情况
本人家庭宽带（运营商：【请填写】，宽带账号：【请填写】），2026年7月31日（近几年）实测发现系统性DNS劫持与非法广告注入，影响智能电视（WhaleyTV）观看视频。

二、DNS劫持证据（可复现）
1. 对公共DNS服务器223.5.5.5（阿里）、114.114.114.114发送UDP 53查询，连续采样10次，9次返回被篡改的异常响应（malformed），污染率90%。
2. 被污染域名覆盖百度、淘宝、腾讯等全网域名（baidu.com污染3/3，taobao.com污染2/3，cdn.qq.com返回0.0.0.1）。
3. 同一域名改用TCP 53查询，全部正常返回；改用DNS-over-HTTPS（DoH）查询，全部正常。
4. 结论：DNS服务器本身正常，污染发生在运营商UDP 53明文DNS通道（DNS poisoning）。

三、非法广告注入证据
1. 腾讯视频播放时，非法广告（保健品/赌博/诱导充值类）替换正常广告，广告流量直连以下海外服务器IP：201.234.234.61（委内瑞拉Level 3）、154.174.194.154（加纳MTN）、85.223.202.42（乌克兰Kyivstar）。上述IP均非腾讯CDN节点且中国大陆不可达，属劫持服务器。
2. 广告SDK域名tencent-dtv.m.cn.miaozhen.com（秒针广告系统）被劫持，HTTPS隧道14次连接被拦截。
3. 注入响应含透明代理标记：Via: 1.1、x-via: 1.1 inXX:XX (Cdn Cache Server V2.0)。
4. 已用开源工具AdJustice采集50条拦截证据（含时间戳、域名、响应头），证据文件可提供。
