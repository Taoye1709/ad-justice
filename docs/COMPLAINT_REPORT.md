# 运营商 DNS 劫持与广告注入 举报材料

> **举报人网络环境：** 家庭宽带，路由器：家庭路由器（内网地址）
> **受害设备：** WhaleyTV WTV55K1J 智能电视（Android 5.0.2，WUI 2.0）
> **证据采集时间：** 2026-07-31 16:14 ~ 17:35（CST）
> **证据采集工具：** AdJustice（开源，GPL-3.0，源码：https://github.com/Taoye1709/ad-justice）
> **所有证据均在设备本地采集，未上传任何第三方服务器。**

---

## 一、举报事项

1. **全网 DNS 劫持**：运营商在 UDP 53 明文 DNS 通道上，对公共 DNS
   服务器（223.5.5.5、114.114.114.114、119.29.29.29、8.8.8.8、1.1.1.1）
   的查询响应进行系统性篡改，覆盖包括百度、淘宝、腾讯在内的所有网站域名。
2. **非法广告注入**：视频播放过程中，非法广告（保健品、赌博、诱导充值类）
   被注入替换正常广告，受害应用为腾讯视频（com.ktcp.video）。
3. **证据特征**：注入流量指向海外广告服务器 IP（委内瑞拉、加纳、乌克兰），
   响应含透明代理注入标记。

## 二、DNS 劫持证据（可复现）

### 2.1 UDP 53 高概率污染（2026-07-31 17:33 实测）

对公共 DNS `223.5.5.5`（阿里 DNS）发送 UDP 53 查询，连续采样：

| 域名 | 污染次数 / 总采样 | 说明 |
|---|---|---|
| vv.video.qq.com | 9 / 10 | 90% 被篡改 |
| www.baidu.com | 3 / 3 | 100% 被篡改 |
| www.taobao.com | 2 / 3 | 66% 被篡改 |
| cdn.qq.com | 2 / 3 | 66% 被篡改 |
| btrace.qq.com | 2 / 3 | 66% 被篡改 |

**污染特征**：`dig` 返回 `Message parser reports malformed message packet`
（响应包被篡改），或返回异常 IP（如 `cdn.qq.com → 0.0.0.1`）。

### 2.2 TCP 53 对照实验（关键证据）

同一时刻、同一域名、同一 DNS 服务器，改用 TCP 53 查询：

| DNS 服务器 | UDP 53 | TCP 53 |
|---|---|---|
| 223.5.5.5 | ❌ malformed | ✅ 正常返回 3 条记录 |
| 114.114.114.114 | ❌ malformed | ✅ 正常返回 3 条记录 |

> **结论**：DNS 服务器本身正常（TCP 查询正确），污染发生在 **UDP 53
> 明文通道**上——即运营商网络设备的 DNS 响应篡改（DNS poisoning）。

### 2.3 DoH 对照实验

通过 DNS-over-HTTPS（doh.pub）解析 `vv.video.qq.com`：
正常返回腾讯 CDN 节点 `ins-giuzhgwa.ias.tencent-cloud.net`（42.81.178.72 / 42.81.178.232）。

## 三、广告注入证据

### 3.1 腾讯视频被劫持连接的广告服务器 IP

2026-07-31 广告播放期间，腾讯视频进程（uid 10037）建立以下直连：

| IP 地址 | 归属 | 国家/运营商 | 备注 |
|---|---|---|---|
| 201.234.234.61 | Level 3 | 委内瑞拉 | 广告播放时活跃连接 |
| 154.174.194.154 | Scancom | 加纳（MTN） | 广告播放时活跃连接 |
| 85.223.202.42 | Kyivstar | 乌克兰 | 被劫持解析 |
| 36.110.110.189 | Chinanet | 中国北京 | 被劫持解析 |

> 这些 IP 均非腾讯 CDN 节点（腾讯 CDN 位于 42.81.x.x 等），且在中国大陆
> 网络不可达（连接超时），但腾讯视频显示连接已建立——典型 TCP 层劫持 /
> 透明代理接管特征。

| vod.aginomoto.com | 11 | Whaley 广告服务器 |
| passport.aginomoto.com | 10 | Whaley 广告服务器 |
| appstore.aginomoto.com | 4 | Whaley 广告服务器 |

### 3.3 注入响应特征

被拦截的 HTTP 响应包含以下透明代理注入标记（正常源站不应出现）：

```
Via: 1.1                              ← 透明代理标记
x-via: 1.1 inXX:XX (Cdn Cache Server V2.0)
Server: openresty/1.27.1.2
x-ws-request-id: xxxxxxxx_xxx_xxxxx-xxxxx
```

## 四、攻击链还原

```
用户播放视频（腾讯视频）
   │
   ▼
应用解析广告域名（*.qq.com / miaozhen.com 等）
   │
   ▼
UDP 53 查询 → 运营商篡改 DNS 响应 → 返回海外广告服务器 IP
   │
   ▼
应用直连被劫持 IP（绕过系统代理）→ TCP 连接被透明代理接管
   │
   ▼
非法广告（保健品/赌博/诱导充值）替换正常广告，注入视频流
```
